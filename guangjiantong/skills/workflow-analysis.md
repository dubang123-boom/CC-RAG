# 分析工作流指导（Flow 1）

## 步骤1：识别文书类型

确认上传文书是：
- **行政处罚事先告知书** — 可提陈述申辩，这是目标文书类型，进入正常流程
- **行政处罚决定书** — 申辩窗口已关闭，在 defensibility_reason 中提示用户考虑行政复议（60日内）或行政诉讼（6个月内）
- **立案通知书/调查通知书** — 还在调查阶段，在 defensibility_reason 中提示用户提前准备证据材料

如果无法确定文书类型，在 questions 中追加一道确认题。

## 步骤2：提取结构化信息

必须提取以下字段，缺失的标注为 null：

| 字段 | 说明 | 示例 |
|------|------|------|
| 案号 | 文书编号 | 深龙华市监罚告〔2024〕0523号 |
| 被处罚主体 | 企业/个人名称 | 深圳市美优家居用品有限公司 |
| 统一社会信用代码 | 18位代码 | 91440300MA5FXXXX2Q |
| 法定代表人 | 负责人姓名 | 陈丽华 |
| 处罚机关 | 执法机关全称 | 深圳市龙华区市场监督管理局 |
| 违规事实 | 告知书认定的全部违法行为 | — |
| 引用法律条款 | 处罚依据的全部法条 | 《广告法》§9③→§57① |
| 拟处罚金额 | 罚款总金额 | 200,000元 |
| 其他处罚措施 | 没收、吊证、停业等 | 责令停止发布违法广告 |
| 申辩期限 | 告知书载明的期限 | 5个工作日 |
| 文书日期 | 告知书落款日期 | 2024年7月25日 |

## 步骤3：判断违规类型

按以下分类判断（一个文书可能涉及多种违规，列出全部）：

### 广告类
1. 绝对化用语/极限词（《广告法》§9③→§57）
2. 保健食品/食品疾病功效宣传（《广告法》§17/§18→§55/§58）
3. 虚假广告（《广告法》§28→§55）
4. 未经审查发布广告（《广告法》§46→§58）
5. 互联网广告未标明"广告"（《互联网广告管理办法》§9）
6. 使用国家机关名义（《广告法》§9①→§57）

### 食品安全类
7. 经营过期食品（《食品安全法》§34→§124）
8. 无证/超范围经营食品（《食品安全法》§35→§122）
9. 从业人员无健康证（《食品安全法》§45→§126）
10. 食品标签标识不合规（《食品安全法》§67→§125）

### 反不正当竞争类
11. 虚假宣传/刷单炒信（《反不正当竞争法》§8→§20）
12. 商业混淆/仿冒（《反不正当竞争法》§6→§18）
13. 不正当有奖销售（《反不正当竞争法》§10→§22）

### 价格类
14. 价格欺诈（《价格法》§14 + 《明码标价和禁止价格欺诈规定》）
15. 不明码标价（《价格法》§13→《价格违法行为行政处罚规定》）

### 产品质量类
16. 产品质量不合格（《产品质量法》§49/§50）
17. 产品标识违规（《产品质量法》§27→§54）

### 商标/知识产权类
18. 商标侵权（《商标法》§57→§60）

### 消费者权益类
19. 欺诈消费者（《消费者权益保护法》§55 + 《侵害消费者权益行为处罚办法》）

### 电子商务类
20. 电商平台/经营者违规（《电子商务法》§15/§17/§38）

### 市场主体登记类
21. 无照经营（《无证无照经营查处办法》）
22. 虚假登记（《防范和查处假冒企业登记违法行为规定》）

### 其他
23. 计量违法（《计量法》）
24. 传销/直销违规（《禁止传销条例》《直销管理条例》）

## 步骤4：评估申辩空间

### 评估维度

| 维度 | 强 | 中 | 弱 |
|------|-----|-----|-----|
| 事实争议 | 告知书认定事实有明显错误 | 部分事实可争议 | 事实清楚无争议 |
| 法律适用 | 适用条款有明显错误 | 裁量幅度偏高有争议空间 | 法律适用准确 |
| 程序合规 | 存在严重程序违法 | 存在程序瑕疵 | 程序合规 |
| 从轻情节 | 首违+已改正+后果轻微（符合不予处罚） | 有部分从轻情节 | 无明显从轻情节 |
| 时效 | 超过追诉时效 | 接近时效 | 时效内 |

### 评估结果

**强（有较大减罚空间甚至可免罚）：**
- 存在程序违法（未告知权利等）
- 法律定性有明显争议
- 符合不予处罚条件（首违+轻微+已改正）
- 有《广告绝对化用语执法指南》等规范性文件支持

**中（有一定减罚空间）：**
- 首次违规且已主动整改
- 处罚幅度偏高，有量罚争议空间
- 有部分从轻情节

**弱（申辩空间有限，但仍应申辩）：**
- 违规事实清楚，法律适用准确
- 非首次同类违规
- 处罚幅度在合理范围内
- 注意：即使评估为"弱"，仍应建议用户提交申辩书——申辩不会加重处罚（§45）

### 罚款金额合理性速查

| 处罚领域 | 法定最低线 | 如果拟处罚款接近最低线 | 如果拟处罚款远高于最低线 |
|---------|-----------|-------------------|---------------------|
| 广告极限词 §57 | 20万 | 争取不予处罚 | 争取降到最低线 |
| 虚假广告 §55 | 广告费3倍或20万 | 争取不予处罚 | 争取减轻到20万以下 |
| 食品过期 §124 | 5万（货值<1万） | 争取从轻到5万 | 争取货值重新核算降低基数 |
| 虚假宣传 反不竞§20 | 20万 | 争取不予处罚 | 争取降到最低线 |

## 步骤5：生成问卷（最多8道题）

**核心原则：问卷必须从本案处罚文书的具体内容动态生成，禁止套用固定模板。**

### 5.1 先提取，再设计

在设计问题之前，必须先完成以下提取工作：

1. **逐项列出**文书认定的每一个具体违法事实/表述/行为
2. **标注类型**：每项违法事实属于哪种类型（绝对化用语、功效超范围、消费者证言、虚假宣传、数据排名、食品安全、价格欺诈等）
3. **摘出数字**：文书中提到的所有量化数据（浏览量、销售额、违法持续时间、涉及平台数等）

### 5.2 必问基础问题（2道，所有案件通用）

**Q-整改（type: text, required: true）**
text: "涉案[根据文书具体内容填写：广告/商品/行为]是否已整改？如已整改，请说明具体做了什么、什么时间完成的（如未整改请填'未整改'）"
why: 引用《行政处罚法》第三十二条说明从轻意义。整改的具体内容和时间是论证"及时改正"的关键事实依据

**Q-历史处罚（type: boolean, required: true）**
text: "贵公司此前是否因同类违规受到过行政处罚？"
why: 引用《行政处罚法》第三十三条说明"首违不罚"意义

### 5.3 量化数据问题（1-2道，必须引用文书中的具体数字）

**如果文书提到了具体数字**，必须在问题中引用：
- 文书称"浏览量超过50万次" → 问"处罚文书认定涉案广告浏览量超过50万次，贵公司后台实际浏览数据是多少？涉案商品总销量和销售额分别是多少？"
- 文书称"违法行为持续约5个月" → 问"文书认定违法行为持续约5个月，实际发布和下架的具体日期？"
- 文书称"货值金额3万元" → 问"文书认定涉案货值3万元，实际进货价格和数量？是否已全部销售？"

**如果文书未提及具体数字**，引导用户提供关键量化信息（浏览量/销量/销售额/广告费用等）。

**消费者投诉**（建议合并到量化数据题中追问，或单独1道 boolean 题）：
"涉案期间是否收到过消费者因此导致的投诉、举报或退货？"
→ 零投诉是"危害后果轻微"的关键证据

### 5.4 违法事实专项问题（每项违法事实各1道 choice 题）

**核心规则：每项违法事实必须有独立问题，禁止合并。** 如总题数将超过8道，可将最相似的2项合并为1道。

根据违法事实类型，设计不同的问法和选项：

**A. 绝对化用语**（"最好""顶级""第一"等）
→ 问该表述是否有事实依据
→ options 根据表述特点定制：
  - 品质/效果类 → ["有第三方检测对比数据", "有权威认证", "无依据"]
  - 排名/销量类 → ["有平台官方数据", "有第三方统计报告", "有限定条件的真实数据", "无依据"]
  - 材质/等级类 → ["有国家/行业标准依据", "有检测报告", "无依据"]
  - 品牌/奖项类 → ["有第三方机构奖项/排名", "有行业协会认证", "无依据"]

**B. 功效宣传超范围**（批准功能为X，却宣传Y）
→ 问超范围功效是否有科学依据
→ text 中必须指出批准功能和实际宣传的差异
→ options: ["有临床试验或科研论文支持", "该表述来自产品原料的公开研究文献", "无额外科学依据"]

**C. 消费者证言/用户评价/代言**
→ 问证言的真实性和来源，text 中引用文书中的具体证言内容
→ options: ["有真实消费者及其书面授权", "来自真实用户但经过编辑加工", "系编造或无法核实"]

**D. 虚假宣传/数据排名**（"全网销量第一"等可验证的数据声明）
→ 问数据来源，text 中引用文书中的具体表述
→ options: ["有平台官方数据截图", "有第三方统计报告", "有限定条件下的真实数据", "无依据"]

**E. 食品安全违规**
→ 根据具体行为设计：如过期食品→"是否已实际销售？剩余数量？"

**F. 价格违法**
→ 如"标注的'原价'是否有7日内真实交易记录？"

**G. 未经审查发布广告/其他广告违规**
→ 根据具体违规行为设计针对性问题

### 5.5 听证意愿（罚款≥较大数额标准时追加1道 boolean）

text: "拟处罚款达到听证标准，您是否考虑同时申请听证？"
why: 说明听证的战略价值（争取时间、质证证据、促使审慎审查）

### 5.6 设计要点

1. **总题数不超过8道**——基础2道 + 量化1-2道 + 违法事实各1道（超限时合并相似项）
2. **每题必须有 why 字段**——用通俗语言解释对申辩的影响
3. **避免问"是否知道违法"**——与申辩无关且可能不利
4. **required 设置**：基础2题为 required: true，其余为 false
5. **key 用有意义的命名**——如 claim_sales_first, effect_tumor, testimony_blood_sugar，不要用 claim_1, claim_2 等无意义编号
6. **choice 的 options 必须针对该具体问题定制**，禁止所有问题用相同选项模板
