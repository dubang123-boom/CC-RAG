# 陈述申辩意见书 — 专业法律文书标准

## 一、格式规范

**标题：** 居中，加粗，"陈述申辩意见书"

**收件方：** 顶格，"[XX市/区市场监督管理局]："

**事由：** 关于[案号]《行政处罚告知书》的陈述申辩意见

**申请人信息块：**
```
申请人：[企业全称]
统一社会信用代码：[代码]
住所：[注册地址]
法定代表人：[姓名]
联系电话：[电话]
```

**落款：**
```
申请人：[企业名称]（加盖公章）
法定代表人签字：___________
日期：____年____月____日
```

## 二、正文结构与写作规范

### 第一部分：关于违法事实的陈述

**写作原则：逐条分析，能争议的争议，不能争议的简短承认。**

**正确写法：**
- 对事实无异议的：简短确认，一句话带过，不要大段复述告知书内容
- 对事实有异议的：明确指出争议点，提出具体反驳理由和证据
- 对法律定性有异议的：援引具体法律条款或规范性文件说明理由

**示例（极限词案件——有证据可辩的项目）：**
> 关于"销量遥遥领先"的认定，申请人认为该表述具有事实依据。根据拼多多平台后台数据显示（详见附件三），申请人涉案商品在2024年5月至7月期间，在"不锈钢保温杯"品类中月均销量排名前3，该表述系对限定时间段内客观销售数据的描述，而非无限定条件的排他性宣传。依据《广告绝对化用语执法指南》第六条第六项，在限定具体时间、地域等条件下，表述时空顺序客观情况或者宣传产品销量、销售额、市场占有率等事实信息的，不属于绝对化用语。
>
> 注意：此论证之所以有力，是因为当事人确实持有"平台后台数据截图"作为证据。

**示例（极限词案件——没有证据应承认的项目）：**
> 关于涉案广告中使用"保温效果最好"一词，申请人对此事实不持异议，该表述确属《中华人民共和国广告法》第九条第（三）项规定的绝对化用语。
>
> 注意：当事人无法提供"保温效果最好"的检测对比数据，因此不应勉强辩解，用一句话承认即可。

**错误示例（捏造证据——绝对禁止）：**
> ❌ 关于"行业第一品牌"的认定，该表述来源于第三方机构颁发的奖项。依据《广告绝对化用语执法指南》第六条第五项...
>
> 为什么错？处罚文书明确写了"当事人无法提供证明材料"，用户也没有提到任何奖项。这是凭空捏造。

### 第二部分：法律适用分析

**写作原则：每个论点必须引用具体法条全称+条款号，禁止泛泛而谈。**

**必须包含的内容：**
1. 处罚所引用的法律条款是否准确适用于本案
2. 处罚幅度是否合理（引用裁量基准）
3. 如有可适用的规范性文件（如《广告绝对化用语执法指南》），必须引用
4. "从轻""减轻""不予处罚"对应的法律依据必须精确到款项

**示例：**
> 贵局拟依据《中华人民共和国广告法》第五十七条第（一）项处以罚款贰拾万元。申请人认为，根据《中华人民共和国行政处罚法》第三十三条第一款，初次违法且危害后果轻微并及时改正的，可以不予行政处罚。同时，根据市场监管总局2023年3月20日发布的《广告绝对化用语执法指南》第十条第一款，"广告中使用绝对化用语，持续时间短或者浏览人数少，没有造成危害后果并及时改正的，应当依法不予行政处罚；危害后果轻微的，可以依法从轻、减轻行政处罚"。

### 第三部分：依法应当从轻、减轻或不予行政处罚的事实与理由

**写作原则：每个论点必须有量化数据或证据支撑，禁止空洞结论。**

**结构要求：每条理由按"论点→法律依据→事实证据"三段式展开。**

**示例：**
> **（一）申请人系初次违法**
>
> 依据：《中华人民共和国行政处罚法》第三十三条第一款。
>
> 事实：申请人自2019年成立至今，从未因广告违规受到行政处罚。经查询全国企业信用信息公示系统，申请人无任何行政处罚记录（详见附件一）。
>
> **（二）申请人已主动消除违法行为危害后果**
>
> 依据：《中华人民共和国行政处罚法》第三十二条第（一）项。
>
> 事实：申请人于2024年X月X日（收到贵局调查通知的当日）即全面下架涉案广告内容。下架操作记录显示时间为当日XX时XX分（详见附件二）。此后，申请人对全部在售商品的宣传内容进行了全面合规审查，已建立广告用语内部审核制度（详见附件三：《广告内容合规管理制度》）。
>
> **（三）违法行为危害后果轻微**
>
> 依据：《中华人民共和国行政处罚法》第三十三条第一款。
>
> 事实：涉案广告发布期间（2024年X月至X月），该商品页面累计浏览量约XX次，实际销售XX件，销售额合计XX元。期间未收到任何消费者因广告内容导致的投诉或举报。涉案商品产品质量合格，不存在欺骗消费者的情形（详见附件四：产品质检报告）。

### 第四部分：程序性意见

**写作原则：没有发现程序问题就不写此部分。绝对禁止写"贵局程序合法"。**

只有在确实发现程序瑕疵时才写此部分，例如：
- 未告知陈述申辩权利
- 未告知听证权利
- 执法人员未出示证件或不足2人
- 超过法定办案期限
- 送达程序不规范

### 第五部分：申辩请求

**写作原则：递进式条件句结构，直接用"如贵局经审查认为..."条件从句衔接三级请求，无需任何口语化过渡词。**

**标准结构：**
> 综上所述，申请人的行为符合《中华人民共和国行政处罚法》第三十三条第一款规定的初次违法且危害后果轻微并及时改正的情形，请求贵局依法对申请人**不予行政处罚**。
>
> 如贵局经审查认为本案不符合不予行政处罚条件，鉴于申请人已主动消除违法行为危害后果，符合《中华人民共和国行政处罚法》第三十二条第（一）项规定的减轻行政处罚情形，请求贵局将罚款金额**减至**人民币伍万元整。
>
> 如贵局认为本案亦不符合减轻行政处罚条件，鉴于申请人具有上述从轻处罚情节，请求贵局在法定幅度内对申请人**从轻处罚**，将罚款金额确定为法定最低限额。

**禁止写法：**
- ❌ "首选请求：""次选请求：""底线请求："——正式法律文书不用这种标签
- ❌ "退一步而言""再退一步""退而求其次"——口语化，不严谨
- ❌ "恳请贵局""恳求"——用"请求"即可，不要求情
- ❌ "从轻或减轻"合并表述——从轻和减轻是不同法律概念

## 三、证据清单格式

申辩书应附证据清单，包含两个部分：

### 第一部分：证据清单表格

```
证据清单

编号  证据名称                          证明目的                    页码
一    企业信用信息公示系统查询结果截图    证明申请人系初次违法          X
二    广告下架操作记录截图（含时间戳）    证明申请人已及时改正          X
三    平台商品销售数据截图              证明涉案广告传播范围有限      X
四    消费者投诉记录查询截图            证明未发生消费者投诉          X
五    产品质检报告                      证明产品质量合格              X
六    《广告内容合规管理制度》          证明申请人已建立长效机制      X
```

### 第二部分：附件准备指南

紧跟证据清单表格之后，必须输出附件准备指南，逐一告诉当事人每份附件怎么准备。

**示例：**
> ### 附件准备指南（提交前请按此清单逐一准备）
>
> **附件一：企业信用信息公示系统查询结果截图**
> - 获取方式：登录国家企业信用信息公示系统（https://www.gsxt.gov.cn），输入企业全称搜索，进入企业详情页面，截取"行政处罚信息"栏显示"暂无信息"的完整页面
> - 注意事项：截图须包含查询日期、企业全称，建议使用浏览器截图工具截取完整页面
>
> **附件二：广告下架操作记录截图**
> - 获取方式：登录拼多多商家后台（merchant.pinduoduo.com），进入"商品管理"→"操作日志"，找到涉案商品的下架/修改记录，截取显示操作时间的页面
> - 注意事项：截图须清晰显示操作时间戳（精确到分钟），如店铺已关闭可联系平台客服申请导出操作记录
>
> **附件三：平台商品销售数据截图**
> - 获取方式：登录拼多多商家后台，进入"数据中心"→"商品分析"，导出涉案商品在违法期间（2024年5月至7月）的浏览量、销量数据
> - 注意事项：数据须覆盖涉案广告发布的完整期间
>
> ...（与证据清单一一对应）

## 四、语言风格规范

### 必须遵守

| 规则 | 正确示例 | 错误示例 |
|------|---------|---------|
| 使用正式法律文书语言 | "申请人对上述事实不持异议" | "我们承认确实犯了错" |
| 用"申请人"自称 | "申请人于X日下架涉案广告" | "我公司立即处理了" |
| 引用法条用全称 | "《中华人民共和国行政处罚法》第三十三条第一款" | "行政处罚法§33" |
| 日期用完整格式 | "2024年7月26日" | "7.26" |
| 金额用大写 | "人民币贰拾万元整（¥200,000.00）" | "20万块" |
| 结论有依据支撑 | "浏览量仅XX次，未收到投诉" | "影响不大""后果不严重" |

### 绝对禁止

1. **禁止写"不知道违法""不了解法律规定"** — 不知法不免责，这不是抗辩理由，写了反而暴露当事人法律意识薄弱
2. **禁止写"并非故意""无意违法"** — 行政处罚一般不要求主观故意（除非法律明确规定），强调主观意图无意义
3. **禁止确认程序合法** — 不要写"贵局调查程序合法""未发现程序违法"，这等于帮执法机关背书
4. **禁止使用方括号占位符** — 所有信息必须从原始处罚文书和用户回答中提取，输出完整文书
5. **禁止情绪化表达** — 不要写"恳请开恩""企业经营困难请求照顾"等感情化表述
6. **禁止重复论述** — 每个论点只出现一次，不同段落不要反复说同一个意思

## 五、听证申请书格式

**标题：** 听证申请书

```
申请人：[企业全称]
统一社会信用代码：[代码]
住所：[注册地址]
法定代表人：[姓名]

被申请机关：[市场监督管理局名称]

申请事项：依据《中华人民共和国行政处罚法》第六十三条，就贵局
[案号]《行政处罚告知书》拟处罚款人民币[大写金额]（¥[数字]）
一案，申请举行听证。

申请理由：
申请人对贵局认定的违法事实及拟作出的处罚决定存在异议，需要通过
听证程序进行陈述和质证。具体理由详见申请人同日提交的《陈述申辩
意见书》。

此致
[市场监督管理局名称]

申请人：[企业名称]（盖章）
法定代表人：________（签字）
日期：____年____月____日
```

**注意事项：**
- 听证申请必须在收到告知书后 **5个工作日** 内提交（2021年修订后的期限）
- 务必保留提交凭证（EMS回执、送达回证或窗口签收记录）
- 听证申请与陈述申辩意见书可以同时提交，互不影响
- 如果罚款金额未达到当地"较大数额"标准，不享有听证权
