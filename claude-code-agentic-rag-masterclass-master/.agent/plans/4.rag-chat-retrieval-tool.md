# Sub-Plan 4: RAG Chat with Retrieval Tool

⚠️ **Medium** — 可能需要迭代，有一定複雜性

## Overview

將向量相似度搜索包裝為 OpenAI function-calling tool，在 chat 端點實作多輪 agent loop（最多 5 次迭代），並透過新的 SSE 事件型別（`tool_call`、`tool_result`）讓前端顯示「正在搜尋文件...」狀態。

## Architecture: Agent Loop

```
User message
    ↓
Fetch DB history → build messages list
    ↓
[Agent Loop, max 5 iterations]
    ↓
LLM call with RETRIEVAL_TOOL definition
    ├── finish_reason=stop → 串流文字回應 → 儲存到 DB → done
    └── finish_reason=tool_calls
            ↓
        Execute retrieve_chunks() → 向量搜索
            ↓
        emit SSE: tool_call, tool_result
            ↓
        append tool result to loop_messages
            ↓
        繼續下一輪迭代
```

---

## SSE Event Protocol

| `type` | 額外欄位 | 說明 |
|--------|----------|------|
| `delta` | `content: string` | 文字 chunk，即時顯示 |
| `tool_call` | `tool: string`, `query: string` | LLM 正在呼叫工具 |
| `tool_result` | `content: string` | 取回結果的預覽（前 200 字） |
| `done` | — | 串流完成 |
| `error` | `content: string` | 致命錯誤 |

### Task 4.1 — 建立 `retrieval_service.py`

```python
# backend/app/services/retrieval_service.py
from supabase import Client
from app.services.embedding_service import embed_texts
from dataclasses import dataclass


@dataclass
class RetrievalResult:
    chunk_id: str
    document_id: str
    content: str
    chunk_index: int
    similarity: float


def retrieve_chunks(
    query: str,
    user_id: str,
    supabase: Client,
    match_count: int = 5,
    match_threshold: float = 0.7,
) -> list[RetrievalResult]:
    """
    Embed the query, run vector similarity search via match_chunks RPC.
    Returns results ordered by similarity (highest first).
    Returns empty list if no matches above threshold.
    """
    embedding = embed_texts([query])[0]

    result = supabase.rpc("match_chunks", {
        "query_embedding": embedding,
        "match_user_id": user_id,
        "match_count": match_count,
        "match_threshold": match_threshold,
    }).execute()

    return [
        RetrievalResult(
            chunk_id=row["id"],
            document_id=row["document_id"],
            content=row["content"],
            chunk_index=row["chunk_index"],
            similarity=row["similarity"],
        )
        for row in (result.data or [])
    ]
```

```python
# backend/app/services/llm_service.py — 新增常數和函數

RETRIEVAL_TOOL = {
    "type": "function",
    "function": {
        "name": "retrieve_documents",
        "description": (
            "Search the user's imported documents for information relevant to the query. "
            "Use this tool when the user's question might be answered by their uploaded documents. "
            "Returns text excerpts ranked by relevance."
        ),
        "parameters": {
            "type": "object",
            "properties": {
                "query": {
                    "type": "string",
                    "description": "The search query to find relevant document excerpts",
                }
            },
            "required": ["query"],
        },
    },
}

SYSTEM_PROMPT = (
    "You are a helpful assistant with access to the user's document library. "
    "When the user asks a question that might be answered by their documents, "
    "use the retrieve_documents tool to search for relevant content. "
    "Always cite which document excerpts you used in your answer. "
    "If no relevant documents are found, answer from general knowledge and say so."
)


def create_chat_stream_with_tools(
    messages: list[dict],
    tools: list[dict] | None = None,
):
    """
    Create a streaming Chat Completions request with optional tool definitions.
    Returns the raw stream object.
    """
    client = get_llm_client()
    kwargs = {
        "model": settings.LLM_MODEL,
        "messages": [{"role": "system", "content": SYSTEM_PROMPT}] + messages,
        "stream": True,
    }
    if tools:
        kwargs["tools"] = tools
        kwargs["tool_choice"] = "auto"
    return client.chat.completions.create(**kwargs)
```

### Task 4.3 — 實作 Agent Loop 在 `routers/chat.py`

```python
# backend/app/routers/chat.py — 完整 send_message 端點
from app.services.llm_service import create_chat_stream_with_tools, RETRIEVAL_TOOL
from app.services.retrieval_service import retrieve_chunks
import json

MAX_TOOL_ITERATIONS = 5

@router.post("/conversations/{conversation_id}/messages")
async def send_message(conversation_id: str, body: MessageCreate, user: dict = Depends(get_current_user)):
    supabase = get_supabase_client()

    # Ownership check
    conv = supabase.table("conversations").select("*") \
        .eq("id", conversation_id).eq("user_id", user["id"]).single().execute()
    if not conv.data:
        raise HTTPException(status_code=404, detail="Conversation not found")

    # Save user message
    supabase.table("messages").insert({
        "conversation_id": conversation_id,
        "user_id": user["id"],
        "role": "user",
        "content": body.content,
    }).execute()

    # Fetch full history
    history = supabase.table("messages").select("role, content") \
        .eq("conversation_id", conversation_id).order("created_at").execute()
    messages = [{"role": m["role"], "content": m["content"]} for m in history.data]

    # Check if user has any complete documents (only offer tool if so)
    doc_check = supabase.table("documents").select("id") \
        .eq("user_id", user["id"]).eq("status", "complete").limit(1).execute()
    has_documents = len(doc_check.data) > 0
    tools = [RETRIEVAL_TOOL] if has_documents else None

    async def event_generator():
        loop_messages = list(messages)
        full_response = ""
        iteration = 0

        try:
            while iteration < MAX_TOOL_ITERATIONS:
                iteration += 1

                # Accumulate streaming response
                accumulated_text = ""
                tool_call_id = None
                tool_call_name = None
                tool_call_args_buffer = ""
                finish_reason = None

                stream = create_chat_stream_with_tools(loop_messages, tools=tools)

                for chunk in stream:
                    choice = chunk.choices[0]
                    delta = choice.delta
                    finish_reason = choice.finish_reason

                    if delta.content:
                        accumulated_text += delta.content
                        full_response += delta.content
                        yield {"event": "message", "data": json.dumps({"type": "delta", "content": delta.content})}

                    if delta.tool_calls:
                        tc = delta.tool_calls[0]
                        if tc.id:
                            tool_call_id = tc.id
                        if tc.function.name:
                            tool_call_name = tc.function.name
                        if tc.function.arguments:
                            tool_call_args_buffer += tc.function.arguments

                # Handle finish reason
                if finish_reason == "stop":
                    break  # 正常文字回應，結束 loop

                if finish_reason == "tool_calls" and tool_call_name == "retrieve_documents":
                    # Parse tool arguments
                    try:
                        args = json.loads(tool_call_args_buffer)
                        query = args.get("query", body.content)
                    except json.JSONDecodeError:
                        query = body.content

                    # 通知前端正在搜索
                    yield {"event": "message", "data": json.dumps({
                        "type": "tool_call",
                        "tool": "retrieve_documents",
                        "query": query,
                    })}

                    # 執行向量搜索
                    results = retrieve_chunks(query, user["id"], supabase)

                    if results:
                        tool_content = "\n\n".join(
                            f"[Excerpt {i+1}, similarity={r.similarity:.2f}]\n{r.content}"
                            for i, r in enumerate(results)
                        )
                    else:
                        tool_content = "No relevant documents found."

                    # 發送結果預覽給前端
                    preview = tool_content[:200] + "..." if len(tool_content) > 200 else tool_content
                    yield {"event": "message", "data": json.dumps({
                        "type": "tool_result",
                        "content": preview,
                    })}

                    # 將 tool call + result 加入 loop messages
                    loop_messages.append({
                        "role": "assistant",
                        "content": None,
                        "tool_calls": [{
                            "id": tool_call_id,
                            "type": "function",
                            "function": {"name": tool_call_name, "arguments": tool_call_args_buffer},
                        }]
                    })
                    loop_messages.append({
                        "role": "tool",
                        "tool_call_id": tool_call_id,
                        "content": tool_content,
                    })
                    continue  # 繼續讓 LLM 基於 retrieved context 生成回應

                break  # 其他 finish_reason，停止

            # 儲存最終文字回應到 DB（tool call rounds 不儲存）
            if full_response:
                supabase.table("messages").insert({
                    "conversation_id": conversation_id,
                    "user_id": user["id"],
                    "role": "assistant",
                    "content": full_response,
                }).execute()

            # Auto-title
            if conv.data.get("title") == "New Conversation" and full_response:
                title = body.content[:50] + ("..." if len(body.content) > 50 else "")
                supabase.table("conversations").update({"title": title}) \
                    .eq("id", conversation_id).execute()

            yield {"event": "message", "data": json.dumps({"type": "done"})}

        except Exception as e:
            yield {"event": "message", "data": json.dumps({"type": "error", "content": str(e)})}

    return EventSourceResponse(event_generator())
```

**關鍵設計說明：**
- Tool call deltas 需要累積（`tool_call_args_buffer`），因為 arguments 以部分 JSON 字串串流到達
- 只有最終文字回應儲存到 DB，tool call rounds 是暫時的
- `MAX_TOOL_ITERATIONS = 5` 防止無限循環
- 無文件時不傳遞 `tools` 參數，避免 LLM 困惑

### Task 4.4 — 更新前端 `streamChat`

```typescript
// frontend/src/lib/api.ts — 更新 streamChat 函數簽名和處理邏輯
export async function streamChat(
  conversationId: string,
  content: string,
  onDelta: (text: string) => void,
  onToolCall: (tool: string, query: string) => void,   // 新增
  onToolResult: (preview: string) => void,              // 新增
  onDone: () => void,
  onError: (error: string) => void,
): Promise<void>

// Event 解析：
if (data.type === 'delta') {
  onDelta(data.content)
} else if (data.type === 'tool_call') {
  onToolCall(data.tool, data.query)
} else if (data.type === 'tool_result') {
  onToolResult(data.content)
} else if (data.type === 'done') {
  onDone()
} else if (data.type === 'error') {
  onError(data.content)
}
```

## Validation Tests

1. 匯入一份關於特定主題的文件，然後詢問相關問題：
   - SSE stream 應發出 `tool_call` → `tool_result` → `delta` 事件
   - 前端顯示 "Searching documents..." 狀態列
   - 最終回答中引用文件內容

2. 詢問無關問題（無相關文件）：
   - LLM 不呼叫工具，直接回答
   - 不出現 retrieval 狀態列

3. 確認 tool call rounds 不儲存到 DB：
   ```sql
   SELECT role, LEFT(content, 50) FROM messages
   WHERE conversation_id = '<id>' ORDER BY created_at;
   -- 應只有 'user' 和 'assistant' 角色，沒有 'tool'
   ```

4. 多輪對話保持歷史：
   - 問一個問題，得到答案
   - 再問跟進問題（"你剛才說的第一點是什麼？"）
   - AI 應能正確引用之前的回答

5. 無文件時測試：
   - 刪除所有文件，詢問問題
   - LLM 不應嘗試呼叫工具

## Provider Compatibility Note

Tool calling 需要 Provider 明確支援：

| Provider | 支援 | 備注 |
|----------|------|------|
| OpenAI | ✅ | 所有模型 |
| OpenRouter | ✅ | 取決於所選模型 |
| Ollama | ⚠️ | 需要 llama3.1, mistral-nemo, qwen2.5 等 |
| LM Studio | ⚠️ | 取決於 GGUF 模型 |

若 Provider 不支援 tool calling，改用「always-retrieve」模式：每次請求前先做向量搜索，將結果注入 system prompt，而不是透過 tool call 機制。
