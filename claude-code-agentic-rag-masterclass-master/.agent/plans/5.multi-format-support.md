# Module 5: Multi-Format Document Support (Mistral OCR)

## Complexity Rating

✅ **Simple** — 1 个新服务文件 + 5 个文件的定点修改。无数据库变更，无新路由。

---

## Architecture

```
Upload → documents.py (validates ALLOWED_TYPES)
           ↓
         import_service._extract_text(content, file_type)
           ├── txt / md  → UTF-8 decode  [unchanged]
           ├── pdf       → ocr_service.extract_with_ocr(content, "pdf")
           └── jpg/jpeg/png/gif/webp/tiff/bmp
                         → ocr_service.extract_with_ocr(content, file_type)
                               ↓
                           Mistral OCR API (mistral-ocr-latest)
                               ↓
                           "\n\n".join(page.markdown for page in result.pages)
```

## Step 3 — `backend/app/services/ocr_service.py` (NEW)

```python
import base64
from mistralai import Mistral
from app.config import settings

_IMAGE_MIME: dict[str, str] = {
    "jpg":  "image/jpeg",
    "jpeg": "image/jpeg",
    "png":  "image/png",
    "gif":  "image/gif",
    "webp": "image/webp",
    "tiff": "image/tiff",
    "bmp":  "image/bmp",
}


def extract_with_ocr(content: bytes, file_type: str) -> str:
    if not settings.MISTRAL_API_KEY:
        raise ValueError(
            "MISTRAL_API_KEY is not set. Add it to backend/.env to enable OCR."
        )

    client = Mistral(api_key=settings.MISTRAL_API_KEY)
    encoded = base64.b64encode(content).decode("utf-8")

    if file_type == "pdf":
        document = {
            "type": "document_url",
            "document_url": f"data:application/pdf;base64,{encoded}",
        }
    elif file_type in _IMAGE_MIME:
        mime = _IMAGE_MIME[file_type]
        document = {
            "type": "image_url",
            "image_url": f"data:{mime};base64,{encoded}",
        }
    else:
        raise ValueError(f"ocr_service does not support file type: {file_type}")

    result = client.ocr.process(
        model="mistral-ocr-latest",
        document=document,
    )

    return "\n\n".join(page.markdown for page in result.pages)
```

## Step 4 — `import_service.py` changes

Add import and OCR routing to `_extract_text()`:

```python
from app.services.ocr_service import extract_with_ocr

_OCR_TYPES = {"pdf", "jpg", "jpeg", "png", "gif", "webp", "tiff", "bmp"}

def _extract_text(content: bytes, file_type: str) -> str:
    if file_type in ("txt", "md"):
        return content.decode("utf-8", errors="replace")
    if file_type in _OCR_TYPES:
        return extract_with_ocr(content, file_type)
    raise ValueError(f"Unsupported file type: {file_type}")
```

## Step 5 — `documents.py` changes

```python
ALLOWED_TYPES = {"txt", "md", "pdf", "jpg", "jpeg", "png", "gif", "webp", "tiff", "bmp"}

_IMAGE_TYPES = {"jpg", "jpeg", "png", "gif", "webp", "tiff", "bmp"}
MAX_FILE_SIZE_IMAGES = 10 * 1024 * 1024   # 10 MB
MAX_FILE_SIZE_PDF    = 50 * 1024 * 1024   # 50 MB
MAX_FILE_SIZE_TEXT   = 10 * 1024 * 1024   # 10 MB
```

Replace single size check with:
```python
    content = await file.read()

    if ext == "pdf":
        max_size = MAX_FILE_SIZE_PDF
    elif ext in _IMAGE_TYPES:
        max_size = MAX_FILE_SIZE_IMAGES
    else:
        max_size = MAX_FILE_SIZE_TEXT

    if len(content) > max_size:
        raise HTTPException(
            status_code=413,
            detail=f"File too large. Max {max_size // (1024 * 1024)} MB for .{ext} files.",
        )
```
