# Sub-Plan 1: Architecture Transition (Responses API → Chat Completions)

✅ **Simple** — 可一次執行，低風險

## Overview

將 OpenAI Responses API 完全替換為標準 Chat Completions API（OpenAI 相容），引入由環境變數驅動的 Provider 抽象層，並將對話歷史管理從 OpenAI 管理的 thread 切換為每次請求時從 DB 取得完整歷史後送出。

**架構決策：Option A** — 完全移除 Responses API，無雙軌支援。

---

## Provider 抽象層設計

核心概念：OpenAI Python SDK 支援 `base_url` 參數，因此任何 OpenAI 相容的提供商都可以用同一個 client 操作。

```
環境變數 (config.py)
    ↓
get_llm_client() → OpenAI(base_url=..., api_key=...) → wrap_openai (LangSmith)
    ↓
client.chat.completions.create(model=..., messages=[...], stream=True)
```

**支援的 Provider 配置範例：**

```env
# OpenAI
LLM_BASE_URL=https://api.openai.com/v1
LLM_API_KEY=sk-...
LLM_MODEL=gpt-4o-mini

# OpenRouter
LLM_BASE_URL=https://openrouter.ai/api/v1
LLM_API_KEY=sk-or-v1-...
LLM_MODEL=anthropic/claude-3.5-sonnet

# Ollama (本機)
LLM_BASE_URL=http://localhost:11434/v1
LLM_API_KEY=ollama
LLM_MODEL=llama3.2

# LM Studio (本機)
LLM_BASE_URL=http://localhost:1234/v1
```

### Task 1.2 — 建立 `llm_service.py`

此為 Provider 抽象層核心，取代 `openai_service.py`：

```python
# backend/app/services/llm_service.py
import os
from openai import OpenAI
from app.config import settings

_llm_client = None
_embedding_client = None


def _build_client(base_url: str, api_key: str) -> OpenAI:
    """Build an OpenAI-compatible client, wrapping with LangSmith if configured."""
    # Set LangSmith env vars
    os.environ.setdefault("LANGSMITH_TRACING", str(settings.LANGSMITH_TRACING).lower())
    if settings.LANGSMITH_API_KEY:
        os.environ.setdefault("LANGSMITH_API_KEY", settings.LANGSMITH_API_KEY)
        os.environ.setdefault("LANGSMITH_PROJECT", settings.LANGSMITH_PROJECT)

    client = OpenAI(base_url=base_url, api_key=api_key)

    if settings.LANGSMITH_API_KEY:
        try:
            from langsmith.wrappers import wrap_openai
            client = wrap_openai(client)
        except ImportError:
            pass

    return client


def get_llm_client() -> OpenAI:
    global _llm_client
    if _llm_client is None:
        _llm_client = _build_client(settings.LLM_BASE_URL, settings.LLM_API_KEY)
    return _llm_client


def get_embedding_client() -> OpenAI:
    global _embedding_client
    if _embedding_client is None:
        base_url = settings.EMBEDDING_BASE_URL or settings.LLM_BASE_URL
        api_key = settings.EMBEDDING_API_KEY or settings.LLM_API_KEY
        _embedding_client = _build_client(base_url, api_key)
    return _embedding_client


def create_chat_stream(messages: list[dict], system_prompt: str | None = None):
    """
    Create a streaming Chat Completions request.
    messages: list of {"role": "user"|"assistant", "content": "..."}
    Returns the raw stream object.
    """
    client = get_llm_client()
    all_messages = []
    if system_prompt:
        all_messages.append({"role": "system", "content": system_prompt})
    all_messages.extend(messages)

    return client.chat.completions.create(
        model=settings.LLM_MODEL,
        messages=all_messages,
        stream=True,
    )
```

**驗證：** `python -c "from app.services.llm_service import get_llm_client; c = get_llm_client(); print(type(c))"` 不報錯。

### Task 1.4 — 重寫 `routers/chat.py` 的 `send_message`

核心變化：
- 不再使用 `openai_response_id`
- 每次請求從 DB 取得完整歷史，組成 `messages` list 送給 Chat Completions
- 解析 `chunk.choices[0].delta.content`（而非 `event.delta`）
- 不再更新 `openai_response_id`

```python
from app.services.llm_service import create_chat_stream
import json

@router.post("/conversations/{conversation_id}/messages")
async def send_message(conversation_id: str, body: MessageCreate, user: dict = Depends(get_current_user)):
    supabase = get_supabase_client()

    # Verify ownership
    conv = supabase.table("conversations").select("*") \
        .eq("id", conversation_id).eq("user_id", user["id"]).single().execute()
    if not conv.data:
        raise HTTPException(status_code=404, detail="Conversation not found")

    # Save user message
    supabase.table("messages").insert({
        "conversation_id": conversation_id,
        "user_id": user["id"],
        "role": "user",
        "content": body.content,
    }).execute()

    # Fetch full history (including the message just saved)
    history = supabase.table("messages").select("role, content") \
        .eq("conversation_id", conversation_id).order("created_at").execute()
    messages = [{"role": m["role"], "content": m["content"]} for m in history.data]

    async def event_generator():
        full_response = ""
        try:
            stream = create_chat_stream(messages)

            for chunk in stream:
                delta = chunk.choices[0].delta
                if delta.content:
                    full_response += delta.content
                    yield {"event": "message", "data": json.dumps({"type": "delta", "content": delta.content})}

            # Save assistant message
            supabase.table("messages").insert({
                "conversation_id": conversation_id,
                "user_id": user["id"],
                "role": "assistant",
                "content": full_response,
            }).execute()

            # Auto-title
            update_data = {}
            if conv.data.get("title") == "New Conversation":
                title = body.content[:50]
                if len(body.content) > 50:
                    title += "..."
                update_data["title"] = title
            if update_data:
                supabase.table("conversations").update(update_data) \
                    .eq("id", conversation_id).execute()

            yield {"event": "message", "data": json.dumps({"type": "done"})}

        except Exception as e:
            yield {"event": "message", "data": json.dumps({"type": "error", "content": str(e)})}

    return EventSourceResponse(event_generator())
```

**注意：** 移除 `create_response_stream` import，改為 `create_chat_stream`。
