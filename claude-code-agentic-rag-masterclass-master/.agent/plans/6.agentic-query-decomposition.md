# Module 6: Agentic Query Decomposition + Self-Reflection

## Complexity Rating

⚠️ **Medium** — Builds on existing tool loop. New: decompose_query service + reflection_service (both use Pydantic structured output). Chat router rewritten to linear agentic pipeline. Two new SSE event types + frontend status panel. No DB schema changes.

---

## Overview

Upgrade the single-retrieval agent loop into a true agentic RAG pipeline:

1. **Decompose**: LLM breaks the user's question into 1-3 focused sub-queries (Pydantic structured output).
2. **Retrieve per sub-query**: Each sub-query runs `retrieve_chunks()` independently; results are deduplicated by `chunk_id`.
3. **Synthesize**: LLM generates the final answer using the merged evidence pool.
4. **Self-reflect**: LLM critiques its own answer against the evidence — emits a confidence badge (high / medium / low).

Frontend gains two new SSE event types (`decompose`, `reflect`) shown as an agent status panel below the chat input.

---

## Architecture

```
User message
    ↓
decompose_query(message) → SubQueryPlan (1-3 sub-queries)
    ↓  SSE: { type: "decompose", sub_queries: [...] }
[For each sub-query]
    retrieve_chunks(sub_query) → new chunks (deduplicated)
    SSE: { type: "tool_call", query: sub_query }
    SSE: { type: "tool_result", content: preview }
    ↓
Merge & sort all results by similarity
    ↓
LLM call (merged evidence as tool result) → streaming answer
    ↓  SSE: delta events
reflect_on_answer(question, evidence, answer) → ReflectionResult
    ↓  SSE: { type: "reflect", confidence: "high"|"medium"|"low", note: "..." }
    ↓  SSE: { type: "done" }
```

## Step 1 — `backend/app/services/decompose_service.py` (NEW)

```python
from pydantic import BaseModel, Field
from app.services.llm_service import get_llm_client
from app.config import settings


class SubQueryPlan(BaseModel):
    sub_queries: list[str] = Field(
        description=(
            "1 to 3 focused search queries that together cover the user's question. "
            "Each query should be specific enough to retrieve distinct evidence. "
            "If the question is simple, return exactly 1 query."
        ),
    )
    reasoning: str = Field(
        description="Brief explanation of why you split the question this way (1-2 sentences).",
    )


_DECOMPOSE_PROMPT = (
    "You are a search strategist for a document retrieval system. "
    "Decompose a user's question into 1-3 focused search queries.\n\n"
    "Rules:\n"
    "- Simple, single-topic questions → 1 query (just rephrase for search)\n"
    "- Multi-part questions → 2-3 queries, one per distinct concept\n"
    "- Comparative questions → one query per entity being compared\n"
    "- Each query should be a concise noun phrase or question\n"
    "- Queries should be semantically distinct to avoid redundant retrieval\n"
    "- Maximum 3 sub-queries total."
)


def decompose_query(question: str) -> SubQueryPlan:
    """
    Use LLM structured output to decompose a user question into 1-3 sub-queries.
    Falls back to [question] on any error.
    """
    client = get_llm_client()
    try:
        response = client.beta.chat.completions.parse(
            model=settings.LLM_MODEL,
            messages=[
                {"role": "system", "content": _DECOMPOSE_PROMPT},
                {"role": "user", "content": question},
            ],
            response_format=SubQueryPlan,
        )
        plan = response.choices[0].message.parsed
        # Enforce max 3 sub-queries
        plan.sub_queries = plan.sub_queries[:3]
        return plan
    except Exception:
        return SubQueryPlan(sub_queries=[question], reasoning="Decomposition unavailable; using original query.")
```

**Validation**: Import and call with a complex question; confirm `1 <= len(plan.sub_queries) <= 3`.

## Step 2 — `backend/app/services/reflection_service.py` (NEW)

```python
from typing import Literal
from pydantic import BaseModel, Field
from app.services.llm_service import get_llm_client
from app.config import settings


class ReflectionResult(BaseModel):
    confidence: Literal["high", "medium", "low"] = Field(
        description=(
            "high: answer is well-supported by retrieved evidence. "
            "medium: partially supported; some gaps exist. "
            "low: evidence is insufficient or contradicts the answer."
        )
    )
    note: str = Field(
        description="One sentence explaining the confidence level. If low/medium, state what is missing.",
    )


_REFLECT_PROMPT = (
    "You are a critical evaluator. Given a user question, the retrieved evidence, "
    "and a draft answer, assess how well the answer is supported.\n\n"
    "Rules:\n"
    "- high: all key claims are directly backed by the evidence\n"
    "- medium: most claims supported, but some details are inferred or missing\n"
    "- low: evidence is absent, irrelevant, or contradicts the answer"
)

_MAX_EVIDENCE_CHARS = 3000
_MAX_ANSWER_CHARS = 1000


def reflect_on_answer(question: str, evidence: str, answer: str) -> ReflectionResult:
    """
    Ask the LLM to rate how well the answer is supported by the retrieved evidence.
    Falls back to medium confidence on any error.
    """
    client = get_llm_client()
    user_msg = (
        f"Question: {question}\n\n"
        f"Retrieved evidence:\n{evidence[:_MAX_EVIDENCE_CHARS]}\n\n"
        f"Draft answer:\n{answer[:_MAX_ANSWER_CHARS]}"
    )
    try:
        response = client.beta.chat.completions.parse(
            model=settings.LLM_MODEL,
            messages=[
                {"role": "system", "content": _REFLECT_PROMPT},
                {"role": "user", "content": user_msg},
            ],
            response_format=ReflectionResult,
        )
        return response.choices[0].message.parsed
    except Exception:
        return ReflectionResult(confidence="medium", note="Reflection unavailable.")
```

**Validation**: Call with a question whose answer matches the evidence → expect "high".

## Step 3 — `backend/app/routers/chat.py` (MODIFY)

Replace the `event_generator` with a linear agentic pipeline. Key changes:

1. Import `decompose_query`, `reflect_on_answer`
2. Remove `MAX_TOOL_ITERATIONS` loop — replaced by linear: decompose → retrieve all → synthesize → reflect
3. Inject merged evidence via synthetic tool message (reuses OpenAI tool-message protocol)
4. Emit `decompose` SSE before retrieval, `reflect` SSE after streaming

```python
# New imports at top of chat.py
from app.services.decompose_service import decompose_query
from app.services.reflection_service import reflect_on_answer

# Remove RETRIEVAL_TOOL import and MAX_TOOL_ITERATIONS constant

@router.post("/conversations/{conversation_id}/messages")
async def send_message(conversation_id: str, body: MessageCreate, user: dict = Depends(get_current_user)):
    supabase = get_supabase_client()

    conv = supabase.table("conversations").select("*") \
        .eq("id", conversation_id).eq("user_id", user["id"]).single().execute()
    if not conv.data:
        raise HTTPException(status_code=404, detail="Conversation not found")

    supabase.table("messages").insert({
        "conversation_id": conversation_id,
        "user_id": user["id"],
        "role": "user",
        "content": body.content,
    }).execute()

    history = supabase.table("messages").select("role, content") \
        .eq("conversation_id", conversation_id).order("created_at").execute()
    messages = [{"role": m["role"], "content": m["content"]} for m in history.data]

    doc_check = supabase.table("documents").select("id") \
        .eq("user_id", user["id"]).eq("status", "complete").limit(1).execute()
    has_documents = len(doc_check.data) > 0

    _IMAGE_TYPES = {"jpg", "jpeg", "png", "gif", "webp", "tiff", "bmp"}

    async def event_generator():
        full_response = ""
        tool_content = ""

        try:
            if has_documents:
                # Stage 1: Decompose
                plan = decompose_query(body.content)
                yield {"event": "message", "data": json.dumps({
                    "type": "decompose",
                    "sub_queries": plan.sub_queries,
                    "reasoning": plan.reasoning,
                })}

                # Stage 2: Retrieve per sub-query (deduplicated)
                seen_chunk_ids: set[str] = set()
                all_results = []

                for sub_query in plan.sub_queries:
                    yield {"event": "message", "data": json.dumps({
                        "type": "tool_call",
                        "tool": "retrieve_documents",
                        "query": sub_query,
                    })}

                    results = retrieve_chunks(sub_query, user["id"], supabase)
                    new_results = [r for r in results if r.chunk_id not in seen_chunk_ids]
                    for r in new_results:
                        seen_chunk_ids.add(r.chunk_id)
                    all_results.extend(new_results)

                    yield {"event": "message", "data": json.dumps({
                        "type": "tool_result",
                        "content": f"Found {len(new_results)} new chunk(s) for: \"{sub_query}\"",
                    })}

                # Stage 3: Build merged evidence
                if all_results:
                    all_results.sort(key=lambda r: r.similarity, reverse=True)
                    doc_ids = list({r.document_id for r in all_results})
                    doc_rows = supabase.table("documents").select("id, filename, file_type") \
                        .in_("id", doc_ids).execute()
                    doc_info = {d["id"]: d for d in (doc_rows.data or [])}

                    def _format_excerpt(i: int, r) -> str:
                        doc = doc_info.get(r.document_id, {})
                        filename = doc.get("filename", "unknown")
                        file_type = doc.get("file_type", "")
                        label = (
                            f"Image '{filename}' (OCR-extracted text)"
                            if file_type in _IMAGE_TYPES
                            else f"Document '{filename}'"
                        )
                        return f"[Excerpt {i+1}, source={label}, similarity={r.similarity:.2f}]\n{r.content}"

                    tool_content = "\n\n".join(_format_excerpt(i, r) for i, r in enumerate(all_results))
                else:
                    tool_content = "No relevant documents found."

                # Inject evidence as synthetic tool message
                synthetic_id = "agentic_retrieval_0"
                loop_messages = list(messages) + [
                    {
                        "role": "assistant",
                        "content": None,
                        "tool_calls": [{
                            "id": synthetic_id,
                            "type": "function",
                            "function": {
                                "name": "retrieve_documents",
                                "arguments": json.dumps({"query": body.content}),
                            },
                        }],
                    },
                    {"role": "tool", "tool_call_id": synthetic_id, "content": tool_content},
                ]
                stream = create_chat_stream_with_tools(loop_messages, tools=None)
            else:
                stream = create_chat_stream_with_tools(list(messages), tools=None)

            # Stage 4: Stream answer
            for chunk in stream:
                choice = chunk.choices[0]
                if choice.delta.content:
                    full_response += choice.delta.content
                    yield {"event": "message", "data": json.dumps({
                        "type": "delta",
                        "content": choice.delta.content,
                    })}

            # Stage 5: Self-reflection
            if has_documents and full_response:
                reflection = reflect_on_answer(
                    question=body.content,
                    evidence=tool_content,
                    answer=full_response,
                )
                yield {"event": "message", "data": json.dumps({
                    "type": "reflect",
                    "confidence": reflection.confidence,
                    "note": reflection.note,
                })}

            # Save & auto-title
            if full_response:
                supabase.table("messages").insert({
                    "conversation_id": conversation_id,
                    "user_id": user["id"],
                    "role": "assistant",
                    "content": full_response,
                }).execute()

            if conv.data.get("title") == "New Conversation" and full_response:
                title = body.content[:50] + ("..." if len(body.content) > 50 else "")
                supabase.table("conversations").update({"title": title}) \
                    .eq("id", conversation_id).execute()

            yield {"event": "message", "data": json.dumps({"type": "done"})}

        except Exception as e:
            yield {"event": "message", "data": json.dumps({"type": "error", "content": str(e)})}

    return EventSourceResponse(event_generator())
```

## New SSE Event Protocol (Module 6 additions)

| `type` | New fields | Description |
|--------|-----------|-------------|
| `decompose` | `sub_queries: string[]`, `reasoning: string` | LLM decomposed the question |
| `reflect` | `confidence: "high"\|"medium"\|"low"`, `note: string` | Self-reflection result |

All existing event types (`delta`, `tool_call`, `tool_result`, `done`, `error`) unchanged — fully backward compatible.

---

## Validation Tests

1. **Simple question** → `decompose.sub_queries` has 1 entry → 1 `tool_call` → answer streams → `reflect` with "high" or "medium"
2. **Complex multi-part question** → `sub_queries` has 2-3 entries → multiple `tool_call`/`tool_result` pairs → single synthesized answer
3. **No matching documents** → `tool_content` = "No relevant documents found." → `reflect.confidence` = "low"
4. **No documents uploaded** → no `decompose` or `reflect` events → plain chat (regression-free)
5. **Deduplication** → same `chunk_id` not duplicated across sub-query results
6. **Frontend badge** → `ReflectionBadge` visible after done, disappears after 8s

## Design Notes

- **No LangChain/LangGraph** — raw SDK calls, plain Python control flow (CLAUDE.md compliant)
- **Structured output** — follows `metadata_service.py` pattern from Module 4
- **Synthetic tool_id** — injects evidence via OpenAI tool-message protocol without a real tool-call round-trip
- **Graceful degradation** — both services have try/except fallbacks; pipeline never crashes
- **Cost** — 2 extra `gpt-4o-mini` calls per message (decompose + reflect); negligible cost (~$0.0001)
- **No DB changes** — messages stored as before (only 'user' and 'assistant' roles, no 'tool' rows persisted)
